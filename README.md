# JK BMS Battery Widget

Готові інсталятори Windows x64 та описи оновлень. Вихідного коду програми в цьому репозиторії немає.

Windows x64 installers and release notes. This repository does not contain application source code.

## Завантаження / Download

Відкрийте [останній реліз](https://github.com/Oleksii569/jk-bms-battery-widget-releases/releases/latest) і завантажте файл `.exe`.

Open the [latest release](https://github.com/Oleksii569/jk-bms-battery-widget-releases/releases/latest) and download the `.exe` installer.

Мови / Languages: Українська (типова / default), English.

Починаючи з 2026.10.12 програма перевіряє оновлення автоматично; доступна також кнопка «Перевірити оновлення» в налаштуваннях. Встановлення потребує згоди користувача.

Starting with 2026.10.12, automatic and manual update checks are available. Installing an update requires user confirmation.

Налаштування, історія та логи зберігаються в папці програми та залишаються під час оновлення.

Settings, history and logs are stored in the application folder and preserved during updates.
