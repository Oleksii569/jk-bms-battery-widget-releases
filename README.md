# JK BMS Battery Widget

Програма для Windows, що відображає стан акумулятора з JK BMS через Bluetooth. Основні показники доступні в системному треї, а докладні дані та графіки — у вікні програми.

## Можливості

- **Моніторинг батареї:** рівень заряду, напруга, струм, потужність і температури.
- **Контроль комірок:** таблиця напруг та спільний графік із різними кольорами для кожної комірки.
- **Облік енергії:** окремі графіки накопиченої енергії заряду й розряду у Вт·год за вибраний період.
- **Історія вимірювань:** перегляд графіків, експорт даних у CSV та зображень у PNG.
- **Стан BMS:** індикація MOSFET заряджання й розряджання, балансування та повідомлень про аварії.
- **Автозапуск із Windows** та діагностичне логування.
- **Оновлення через GitHub:** автоматична перевірка, опис змін і встановлення після підтвердження користувача.

## Завантаження

### [Завантажити останню версію для Windows x64](https://github.com/Oleksii569/jk-bms-battery-widget-releases/releases/latest)

На сторінці релізу відкрийте розділ **Assets** і завантажте файл:

`JK-BMS-Battery-Widget-Setup-…-x64.exe`

Опис змін наведено на сторінці кожного релізу.

## Системні вимоги

| Компонент | Вимога |
|---|---|
| Операційна система | Windows 10 або Windows 11, 64-бітна |
| Bluetooth | Адаптер із підтримкою Bluetooth Low Energy (BLE) та встановленими драйверами |
| BMS | Сумісна JK BMS із Bluetooth |
| Інтернет | Потрібний для перевірки та завантаження оновлень |
| Папка встановлення | Має бути доступною для запису налаштувань, історії та логів |
| Python | Окреме встановлення не потрібне |

Моніторинг через Bluetooth працює без інтернету. Сумісність може залежати від моделі та прошивки BMS.

## Встановлення

1. Завантажте інсталятор із останнього релізу.
2. Запустіть файл `.exe`.
3. Виберіть мову та папку встановлення.
4. За потреби позначте **автозапуск із Windows**, **діагностичне логування** та **створення ярлика**.
5. Завершіть встановлення й виберіть свою BMS у налаштуваннях підключення.

Типова папка встановлення:

```text
%LOCALAPPDATA%\Programs\JK BMS Battery Widget
```

Налаштування, історія вимірювань і логи зберігаються в папці програми. Інсталятор не містить попередньо записаних вимірювань чи персональних налаштувань.

## Оновлення

Програма перевіряє нові версії після запуску та кожні 6 годин. Ручна перевірка доступна за шляхом:

**Налаштування → Система → Перевірити оновлення**

Коли з’являється нова версія, програма показує її номер та опис змін. Ви можете вибрати **«Завантажити та встановити»** або **«Пізніше»**.

Перед встановленням перевіряються розмір і контрольна сума SHA-256 завантаженого файла. Оновлення зберігає налаштування, мову, параметри автозапуску й логування, історію та журнали.

**Для переходу з версії 2026.10.7 потрібно один раз запустити новий інсталятор вручну.** Автоматична перевірка оновлень доступна починаючи з версії 2026.10.12.
